# VeinPay mobile

Flutter app for the VeinPay palm vein wallet.

## Run

```powershell
cd palmpay/mobile
flutter run --dart-define=API_HOST=192.168.18.114
```

## Branding

- App display name: **VeinPay**
- Logos: `assets/branding/VeinPay-Light.png` (default / light theme) and `VeinPay-Dark.png` (dark theme)
- Theme: Profile → Appearance (light, dark, or system)

## Tests

```powershell
flutter test
```
